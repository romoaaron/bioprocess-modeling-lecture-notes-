# From Dynamic Bioprocess Models to Metabolic Networks

**Lecture materials for the CIMAT Workshop on Mathematical Modeling of Industrial Processes**

> A unified introduction to dynamic bioprocess modeling, chemostat analysis, and metabolic networks through the common language of mass balances.

---

## Overview

This repository contains the lecture materials, simulation codes, and lecture notes developed for the **CIMAT Workshop on Mathematical Modeling of Industrial Processes (2026)**.

The main goal is to provide a mathematically rigorous yet accessible introduction to two complementary paradigms used in bioprocess modeling:

- **Dynamic models**, based on ordinary differential equations.
- **Metabolic models**, based on stoichiometric constraints and linear optimization.

Although these approaches are often taught separately, these notes emphasize that both arise naturally from the same physical principle: **conservation of mass**.
